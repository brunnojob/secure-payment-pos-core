# Security policy

Este projeto é um laboratório de fluxo de pagamento. Ele não processa transações reais nem deve receber dados de cartão, PIN ou credenciais de adquirência.

## Reporte privado

Não publique detalhes de uma vulnerabilidade em issue pública. Envie um relatório privado ao mantenedor do repositório com:

- descrição do impacto;
- passos reproduzíveis;
- versão ou commit afetado;
- evidências sem dados pessoais ou financeiros.

Não inclua números de cartão, tokens, chaves ou dados de clientes.
