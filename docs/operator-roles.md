# Operator roles

O identificador do operador é gravado em cada venda para auditoria.

A camada de domínio não concede permissões por conta própria: a tela e a camada de autenticação devem garantir que o operador esteja autorizado antes de chamar o checkout. O repositório deve continuar recebendo um identificador explícito, evitando identidade implícita ou compartilhada.
